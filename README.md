# QR-карточки

Создаёте карточку (заголовок, текст, фото) — получаете QR-код, печатаете его из Chrome с компьютера или телефона.
Кто отсканирует QR камерой телефона, увидит страницу с этой информацией и фото.

- **Управление:** https://alex22826.github.io/qr/admin.html
- **Страница после скана:** `https://alex22826.github.io/qr/?c=<код>`

## Как это устроено

Сервера нет — всё живёт в этом репозитории и на GitHub Pages:

| Что | Где |
|---|---|
| Карточки | `cards/<код>.json` |
| Фото (сжатые до 1600 px) | `photos/<код>-<время>.jpg` |
| Страница после скана | `index.html` + `js/view.js` |
| Админка | `admin.html` + `js/admin.js` |
| Работа с GitHub API | `js/github.js` |

Админка сохраняет карточки коммитами через GitHub API (одно сохранение = один коммит).
Pages пересобирается примерно за минуту. Пока он пересобирается, страница просмотра
берёт свежие данные прямо из репозитория (raw.githubusercontent.com).

QR-код ведёт на карточку, а не содержит текст внутри. Поэтому **после печати карточку можно менять**:
напечатанный QR сразу покажет новую информацию. При удалении карточки QR перестаёт работать.

## Первое подключение

**Компьютер (один раз).** Админка покажет кнопку «Открыть GitHub»: ссылка сама заполняет форму ключа
(имя, без срока, право Contents: Read and write). Вручную нужно только выбрать
Repository access → **Only select repositories** → `qr`, нажать **Generate token** и вставить код в админку.

**Телефон — без ввода.** На компьютере нажмите значок телефона вверху → «Показать QR для телефона» и
отсканируйте его камерой. Ссылка вида `admin.html#connect=<ключ>` сохранит ключ в браузере телефона
и сразу уберёт его из адресной строки.

Ключ хранится только в localStorage браузера. Ключ в сам сайт не вшивается: репозиторий публичный,
его бы забрал кто угодно, а GitHub автоматически отзывает такие ключи.
## Важно

- Репозиторий публичный (бесплатный GitHub Pages работает только с публичными), значит
  **всё, что попадает в карточки, видно любому**. Не кладите туда пароли и личные данные.
- Печать: в окне печати Chrome масштаб должен быть **100%**, тогда размер QR будет точным.

## Локальный запуск

```bash
python -m http.server 8800
```

Затем откройте http://localhost:8800/admin.html. Даже при локальном запуске админка работает
с настоящим репозиторием, а QR всегда ведут на публичный адрес Pages.

Админка коммитит карточки прямо в `main`, поэтому перед правкой кода делайте `git pull`.

При изменении `css/` или `js/` увеличивайте `?v=N` в `index.html` и `admin.html`,
иначе браузеры могут показывать старую версию из кэша.
